This proves the build failure is caused by the local MSVC/compiler environment, not by the project source code. In this machine there is plenty of disk space and no `_CL_*` files were found, so the remaining practical fix is repairing/updating Visual Studio C++ Build Tools or running from a fully healthy Developer PowerShell environment.
